# Running the 5 November meeting

The meeting shows the prototype working: upload the Excel file, get the output Excel with the expenses, and see the KPIs. The labels are corrected afterwards, and the results are then updated, even if they are worse.

| Check | How |

## Start the page

```bash
itemizer ui
```

Open <http://127.0.0.1:8000> in a browser on the same machine. Leave the terminal open, and press Control-C to stop it. Nobody else can reach the page.

## The order of the demo

1. **Say who wrote the labels first.** Claude Opus wrote all 200 test labels, and the tool also runs on Claude. So today's accuracy shows how far the tool agrees with those labels, and not that it is right. People check them after this meeting, and the figures may get worse.
2. **Upload the AutoPay file.** The check page shows 1,347 rows, 729 notes, no model calls needed, and full KPIs. Press **Start the run**. It takes a few seconds, and needs no internet.
3. **Show the KPIs on the result page.** Point out both tables: coverage is 99%, but what an accountant can accept without reading is 82% of rows and 50% of dollars.
4. **Download the output Excel,** and open the `Items` sheet: one line per charge, with the exact words it came from. Then the `Largest` sheet.
5. **Open the status page** from the top of the page, for D1, D2 and D3.
6. **Show the page refusing to guess.** A row that does not add up is flagged, and a row the model is unsure about goes to Review.

To show a different file, use one with no email addresses or names, because the scan stops those before anything is sent. The page says what a new file would cost before it starts. It gets the output Excel and coverage, and no accuracy, because test labels exist only for the AutoPay file. New files need internet. The category list has no lumper category, because only 3 of the 729 notes mention one, so a lumper fee shows as "Other or unmapped".

## If the page fails

The same demo works from a terminal, with no page:

```bash
itemizer run
itemizer evaluate
itemizer acceptance d3
```

The output Excel is at `data/runs/<run_id>/itemized.xlsx`, and the `run` command prints the path. The status page is at `data/reports/d3_summary.html`.
